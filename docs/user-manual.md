## システム概要

### Broadlistening とは

Broadlistening は、大量の意見を収集・分析・可視化するためのプラットフォームです。

**主な用途:**
- 市民意見の収集と分析（自治体）
- 社員の声の可視化（企業）
- 顧客フィードバックの構造化（サービス業）
- コミュニティの意見集約（NPO/団体）

### システム構成

```
┌─────────────────────────────────────────────────────┐
│                   ユーザー                           │

    ┌─────────────┼─────────────┐
```

## 意見の収集

### 収集方法の選択

| 方法 | 特徴 | 適した場面 |
|------|------|-----------|
| Forgejo Issue | 構造化、トラッキング可能 | 継続的な意見収集 |
| Webフォーム | 匿名、シンプル | 一般市民向け |
| Slack | 日常会話から抽出 | 社内フィードバック |
| CSV | 既存データ活用 | アンケート結果の取り込み |

### Forgejo Issue からの収集

**手順:**

1. http://localhost:3000 にログイン
2. リポジトリを選択（または新規作成）
3. 「Issues」→「新しいIssue」をクリック
4. 入力項目:
   - **タイトル**: 意見の要約（必須）
   - **本文**: 意見の詳細（必須）
   - **ラベル**: カテゴリ（任意）
5. 「Issueを作成」をクリック

**自動処理:**
- Webhook が自動発火
- Embedding 生成 → Qdrant 保存
- LLM で分類・テーマ抽出
- Web UI に即時反映

### Webフォームからの収集

**手順:**

1. http://localhost:8000/submit.html にアクセス
2. 入力項目:
   - **お名前**: 任意（匿名可）
   - **カテゴリ**: ドロップダウンから選択
   - **ご意見**: 自由記述
3. 「送信」をクリック

**カスタマイズ:**
`web/submit.html` を編集することで、入力項目を変更できます。

### Slack からの収集

**設定手順:**

1. Slack App を作成（[api.slack.com](https://api.slack.com/)）
2. Event Subscriptions を有効化
3. `message.channels` イベントを購読
4. n8n で `slack_to_issue.json` ワークフローを設定
5. Bot を対象チャンネルに招待

**収集ルール:**
- 特定チャンネルの投稿を自動収集
- 特定キーワード（例: `#意見`）を含む投稿のみ収集
- スレッド返信は除外（設定変更可能）

### CSV インポート

**テンプレート形式:**

```csv
title,body,source,category,created_at
"駐車場の問題","駅前の駐車場が少なくて困っています","survey","問題提起","2024-01-15"
"公園の提案","子供が遊べる公園を増やしてほしい","survey","提案","2024-01-16"
```

**実行:**

```bash
# CSVファイルをコンテナにコピー
docker cp your_data.csv broadlistening-n8n:/data/import.csv

# インポート実行
docker exec broadlistening-n8n python3 /scripts/csv_import.py /data/import.csv
```

**オプション:**
```bash
# ヘッダー行をスキップ
--skip-header

# 重複チェック（類似度0.95以上をスキップ）
--deduplicate

# ドライラン（実際には登録しない）
--dry-run
```

## クラスタリングと分析

### クラスタとは

類似した意見を自動的にグループ化したものです。各クラスタには LLM が生成したラベル（要約タイトル）が付与されます。

**例:**
```
クラスタ「交通・駐車場問題」
├── 駅前の駐車場が少ない
├── 駐輪場が狭すぎる
├── 通勤時間の混雑がひどい
└── バスの本数を増やしてほしい
```

### クラスタ一覧

http://localhost:8000/clusters.html

**表示内容:**
- クラスタ名（自動生成ラベル）
- 含まれる意見数
- 主要テーマ
- 代表的な意見（3件）

### クラスタリングの実行

**自動実行（週次バッチ）:**
n8n のスケジュールワークフローで毎週実行。

**手動実行:**
```bash
docker exec broadlistening-n8n python3 /scripts/batch_clustering.py
```

**パラメータ調整:**
```bash
# クラスタ数を指定
--n-clusters 10

# 最小クラスタサイズを指定
--min-size 5

# 類似度閾値を指定
--threshold 0.7
```

### クラスタ要約

各クラスタの要約レポート:

```
=== クラスタ「交通・駐車場問題」===

【概要】
駅前の駐車場・駐輪場の不足に関する意見が集中。
通勤時間帯の混雑が主な課題として挙げられている。

【主な意見】
1. 駐車場の増設を求める声（35%）
2. 駐輪場の拡充を求める声（28%）
3. 公共交通機関の充実を求める声（22%）

【提案された解決策】
- 立体駐車場の建設
- パーク&ライドの推進
- バス便の増便

【関連テーマ】
交通, 駐車場, 駐輪場, 混雑, 通勤
```

## 投票と合意形成

### 投票機能

意見に対して賛成/反対/中立の投票ができます。

**投票方法:**

1. 意見マップでノードをクリック
2. 詳細パネルの「投票」ボタン
3. 賛成/反対/中立を選択

**または投票専用画面:**

http://localhost:8000/voting.html

### 投票結果の分析

**合意度スコア:**
```
合意度 = |賛成率 - 反対率|

1.0: 全員が同じ意見（完全合意）
0.5: やや意見が分かれる
0.0: 賛否が完全に分かれる（完全分断）
```

**分断度スコア:**
```
分断度 = 1 - |賛成率 - 反対率|

高い分断度 = 議論の焦点になりやすい意見
```

### 投票分析画面

http://localhost:8000/voting.html

**表示内容:**

## レポート生成

### 週次レポート

毎週自動生成されるサマリーレポート。

**内容:**
- 期間内の意見数、分類別内訳
- 新規クラスタと主要テーマ
- トレンド分析（テーマの増減）
- 合意度の高い意見/低い意見
- 要対応事項のハイライト

**閲覧:**

http://localhost:8000/reports.html

**手動生成:**
```bash
docker exec broadlistening-n8n python3 /scripts/weekly_summary.py
```

### レポート形式

**HTML形式:**
Web UI で閲覧可能

**JSON形式:**
```bash
curl http://localhost:5000/api/v1/reports/latest
```

**PDF形式（将来対応予定）**

### トレンド分析

テーマの時系列変化を追跡:

```
テーマ「交通」の推移:
  1週目: 15件 ████████████████
  2週目: 23件 ████████████████████████
  3週目: 18件 ██████████████████
  4週目: 31件 ████████████████████████████████ ← 急増

→ 「交通」に関する意見が増加傾向。詳細分析を推奨。
```

## データ管理

### エクスポート

**Web UI から:**
1. 意見マップ右上の「エクスポート」ボタン
2. 形式を選択（JSON/CSV）
3. ダウンロード

**API から:**
```bash
# JSON形式
curl http://localhost:5000/api/v1/issues?format=json > issues.json

# CSV形式
curl http://localhost:5000/api/v1/issues?format=csv > issues.csv
```

### バックアップ

**定期バックアップ:**
```bash
./backup.sh
```

**バックアップ対象:**
- Qdrant: ベクトルデータ
- Forgejo: Issue、ユーザー
- n8n: ワークフロー設定
- Web: JSONデータ

### データ削除

**特定の意見を削除:**
```bash
# API経由
curl -X DELETE http://localhost:5000/api/v1/issues/123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**古いデータを一括削除:**
```bash
docker exec broadlistening-n8n python3 /scripts/qdrant_manager.py \
  cleanup --older-than 365
```

**全データ削除（注意）:**
```bash
docker compose down -v
```

### ユーザー管理
